# pff — 2 pipelines

## pipeline 1 — noto → notosfd (source glyph building)

**purpose:** build source SFD files for each script font from Noto fonts,
user-designed glyphs, and shared base fonts.

**inputs:**
- `pysk/notopy/NotoSans*.ttf` — Noto source fonts (one per Indic script)
- `notosfd/xi38/xe38asc.sfd` — shared base glyphs for xi38 (vowels, marks, etc.)
- `notosfd/xi52/xe52asc.sfd` — shared base glyphs for xi52
- `pysk/notopy/SunnySpells.ttf` — decorative/display source
- `pysk/notopy/noto_map_38.csv` — glyph map for xi38 series
- `pysk/notopy/noto_map_52.csv` — glyph map for xi52 series
- `pysk/notopy/NamesList.txt` — unicode→hskii mapping

**script:**
```
fontforge -script pysk/notopy/noto_copy.py          # both series
fontforge -script pysk/notopy/noto_copy.py xi38     # xi38 only
fontforge -script pysk/notopy/noto_copy.py xi52     # xi52 only
fontforge -script pysk/notopy/noto_copy.py xh38     # one font only
```

**outputs:**
- `notosfd/xi38/x*38asc.sfd` — xi38 source SFDs (10 scripts)
- `notosfd/xi52/x*52asc.sfd` — xi52 source SFDs (10 scripts)

**manual step (between pipeline 1 and 2):**
copy/replace `notosfd/*` → `sfdsrc/` after reviewing in FontForge.
each script designer reviews their own font:
- xh* (Hindi/Devanagari) — Hindi speaker
- xb* (Bengali) — Bengali designer
- xs* (Sinhala), xt* (Tamil), xm* (Malayalam), etc.

## pipeline 2 — sfdsrc → sfd → ttf/woff2 (font generation)

**purpose:** generate final unicode + mono fonts from reviewed source SFDs.

**inputs:**
- `sfdsrc/xi38asc/x*38asc.sfd` — reviewed xi38 source SFDs
- `sfdsrc/xi52asc/x*52asc.sfd` — reviewed xi52 source SFDs
- `sfdsrc/asc-to-utf.json` — ascii→unicode mapping (generated by gen_asc_to_utf_json.py)

**phases (run via main.py):**
```
fontforge -script pysk/xi52py/main.py --phase asc   # build asc fonts
fontforge -script pysk/xi52py/main.py --phase utf   # build utf fonts (unicode ranges)
fontforge -script pysk/xi52py/main.py --phase mono  # build mono fonts
fontforge -script pysk/xi52py/main.py --phase meta  # update font metadata
fontforge -script pysk/xi52py/main.py --phase gen   # generate TTF + WOFF2
```

**key scripts:**
- `pysk/xi52py/glyph_copy/build_asc_fonts.py` — asc phase
- `pysk/xi52py/glyph_copy/build_utf_fonts.py` — utf phase (xi38 only, refs identity matrix)
- `pysk/xi52py/copy_utf_unicode_blocks.py` — copy utf blocks to other 9 xi38 fonts
- `pysk/xi52py/verify_utf.py` — verify utf refs are not collapsed

**outputs:**
- `sfd/xi38sfd/xi38asc/` — xi38 asc SFDs
- `sfd/xi38sfd/xi38utf/` — xi38 utf SFDs (unicode ranges filled)
- `sfd/xi52sfd/xi52utf/` — xi52 utf SFDs
- `xnglofonts/ttf/` — final TTF files
- `xnglofonts/woff2/` — final WOFF2 files

**ci/cd:** `.github/workflows/build-xi52.yml` runs pipeline 2 on every push to main.
