# getting claude support for xnglo non-profit projects

xnglo projects are non-profit education apps aimed at improving literacy rates
by making Indic script learning easier through the xnglo font system.
these projects qualify for multiple Anthropic support programs.

---

## 1. claude for nonprofits — FREE claude max access

**most relevant for xnglo** — gives full Claude Max (highest tier) at no cost.

- **apply**: https://claude.com/solutions/nonprofits
- **what you get**: free Claude Max plan (20x higher usage limits than free tier)
- **who qualifies**: registered nonprofits / NGOs worldwide
- **launched**: December 2025 (partnership with GivingTuesday)

**how to apply**:
1. go to https://claude.com/solutions/nonprofits
2. fill the form — describe xnglo as:
   - non-profit education project
   - improving literacy rates in Indic language communities
   - open source font system for 10 Indic scripts
   - no commercial revenue, public good purpose

> note: this gives **chat access** (claude.ai), not API credits.
> API usage is billed separately via platform.anthropic.com

---

## 2. ai for science — free api credits

for researchers/developers at nonprofits doing high-impact work.

- **apply**: https://www.anthropic.com/news/ai-for-science
- **what you get**: free API credits
- **who qualifies**: researchers at universities or nonprofit organizations
- **xnglo angle**: open source Indic script font system for literacy/education research

---

## 3. claude for education — university programs

if any xnglo contributor is at a partner university:

- **url**: https://claude.com/solutions/education
- **what**: free/discounted Claude for students, faculty, staff with .edu email
- **includes**: API credits for student builders program

**student builders program** (for building with Claude API):
- apply at: https://www.anthropic.com/news/introducing-claude-for-education
- get API credits for education projects

---

## 4. claude for teachers (k-12)

if any xnglo contributor is a teacher:

- **url**: https://claude.com/solutions/teachers
- **what**: free full year of premium Claude for verified teachers
- **deadline**: applications open through June 30, 2027

---

## 5. claude for startups — api credits

if xnglo is registered as a startup (even non-dilutive):

- **url**: contact via https://www.anthropic.com/contact
- **what**: $1,000–$5,000 in API credits (up to $100,000 for equity-funded)
- **note**: startups building on Claude API qualify

---

## 6. open source program — claude max for maintainers

for open source maintainers of active repos:

- **url**: https://claude.com/contact-sales/claude-for-oss
- **what**: Claude Max 20x (6 months free, ~$1,200 value)
- **who qualifies**: maintainers of repos with 5,000+ github stars OR 1M+ npm/month downloads

> xnglo repos currently growing — apply when star count increases.
> anthropic runs similar programs periodically.

---

## 7. practical tips to stay within current limits

while waiting for program approval:

### spread usage across sessions
- use claude for architecture/planning (high value, low messages)
- use github copilot / other tools for repetitive code generation
- batch questions — ask multiple things in one message

### use claude api (pay-as-you-go)
cheaper than Pro for occasional use:
```
platform.anthropic.com → create account → ~$5 free credits to start
claude-haiku-5-5  : cheapest, good for code tasks
claude-sonnet-4-6 : balanced (current model)
```

### use project memory (current session)
- this pff project already has memory enabled
- facts are remembered across sessions → fewer repeated explanations needed

### write good prompts
- give full context in one message
- paste error logs + relevant code together
- say what you already tried

commercial: none — all work is non-profit
