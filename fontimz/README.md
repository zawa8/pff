# fontimz — font rendering images

Screenshots of xnglo fonts rendered in font viewers / browsers.
Designer reference for expected rendering.

## Files

- `xe52ttfimez.png` — xe52asc.ttf rendering example

## Purpose

Visual reference of how xnglo fonts render text:
- Latin words (English)
- Hindi consonants and vowels
- Symbol ranges (EIOUMX → ≡ ≠ → ↓ ≥ ≤)
- Mixed Latin/Hindi (xnglo-style: `xndroid`, `xksre`)

See `scripts/designer_workflow.md` for the designer workflow.
